# monitor-theme-serverstatus

[monitor](https://github.com/monitor-probe/monitor) 的一款公开页主题，沿用经典 ServerStatus 的紧凑表格布局。

![预览](preview.png)

## 安装

从 [Releases](https://github.com/syuim/monitor-theme-serverstatus/releases) 下载
`theme.tar.gz`，在 hub 后台「主题」页上传，或解压到 hub 的 `--themes` 目录下的 `serverstatus/`。
之后可在同一页切换，卡片上的 ⟳ 从本仓库的最新 release 更新：发版时 tag 与 `theme.json` 的
`version` 写成同一个值（`v1.0.0` 对 `1.0.0`），hub 以两者是否一致判断有没有更新。
